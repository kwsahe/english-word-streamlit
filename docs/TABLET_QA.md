## 4. 알려진 한계

- OS 수준 palm rejection을 보장하지 않는다. 브라우저가 보내는 `pointerType`에 의존한다.
- S펜 하드웨어 버튼·지우개 끝(`buttons & 32`)은 브라우저마다 다르다. 지우개는 화면 버튼으로 항상 쓸 수 있다.
- 초안은 이 기기 IndexedDB에만 있다(14일 후 자동 삭제, 로그아웃 시 전체 삭제). 다른 기기로 옮겨지지 않는다.
- 원본 필기 이미지는 DB에 저장하지 않는다. 확인 화면 미리보기와 재인식에만 서버 세션 메모리에서 쓴다.
