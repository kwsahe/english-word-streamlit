## 4. 무작위 복습 vs FSRS 비교 실험 (구현됨, 실제 실행 결과는 아직 없음)

- **질문**: 같은 학습 시간에서 FSRS 일정이 무작위 복습보다 7일 뒤 재시험 정답률을 높이는가?
- **설계**: 학습자 1명 내 단어 무작위 분할(within-subject). 아직 FSRS 기록이 없는 단어 80개를 무작위로 40/40 배정. A군은 FSRS 큐, B군은 같은 하루 복습 횟수로 무작위 출제. 2주 학습.
- **주 지표**: 학습 종료 7일 뒤 두 군 전체 단어 재시험 정답률(같은 형식: 철자 쓰기, 수동 확인).
- **보조 지표**: 오답 회복률, 세션 완료율, 총 복습 횟수, OCR 수정률(필기 품질 통제).
- **분석**: 단어 단위 정답 여부의 두 비율 차이와 부트스트랩 95% 신뢰구간. n=40/군이면 큰 차이만 검출 가능하다는 점을 함께 보고.
- **주의**: 1인 실험이라 일반화하지 않음, 단어 난이도 차이를 무작위 배정으로만 통제, 인과 효과를 과장하지 않음. 결과가 없으면 README에 수치를 쓰지 않음.
- **구현** (`services/experiment.py`, `views/experiment.py`, 🏠 오늘 탭 아래 패널):
  - 시작: 단어 수(20~200, 기본 80)·학습 기간(기본 14일)·대기(기본 7일) 선택 → 시드 고정 무작위 배정, 설정(`profiles.settings.experiment` / 로컬 settings)에 저장
  - 학습 기간: FSRS군은 새 단어 중 먼저 출제되고 평소 FSRS 일정을 따름. 무작위군은 FSRS 큐에서 빠지고, '오늘 FSRS군 복습 횟수 − 오늘 무작위군 복습 횟수'만큼 빠른 복습에 🧪 표시로 섞여 나옴. 무작위군 이벤트는 `mode = experiment-random:*`
  - 대기 기간: 두 군 모두 오늘 탭·쓰기 연습 큐에서 제외
  - 재시험: 뜻 → 철자 입력, 두 군 섞어 시드 고정 순서로 1회씩. 결과는 실험 기록에만 저장(FSRS·복습 이력에 반영 안 함). 실험 중 삭제된 단어는 제외
  - 결과: 군별 재시험 정답률·학습 중 복습 횟수/정답률, 차이와 부트스트랩 95% 신뢰구간(2,000회), JSON 내려받기. 중단한 실험은 분석하지 않음
- **알려진 한계**: 기존 학습 탭(플래시카드·시험·무한)과 '카테고리·범위' 쓰기 연습에서는 실험 단어도 나올 수 있다(두 군에 비슷하게 영향). 쓰기 연습에서 푼 FSRS군 복습도 노출량에 포함된다.
- **테스트**: `tests/test_experiment.py`(배정 재현성·단계·큐 제외·노출량·분석), `tests/test_today_app.py`(시작 → FSRS군/무작위군 교대 → 이벤트 표시, 재시험 20문항 → 결과)
